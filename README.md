## Coding Convention
- Type: PascalCase
- Variable / Function: camelCase
- Constant: SCREAMING_SNAKE_CASE
- ID / JSON Field: camelCase | kebab-case
- Internal: `_` prefix
- Private: `__` prefix

## Coding Style
- Braces: Linux Kernel style
- Parentheses in clauses: attached (`if()`, not `if ()`)
- Struct / Dictionary literals: spaces inside braces
- Trailing comma: disabled
- Indentation: 4 spaces
- TAB or Space: indifferent
- Magic numbers etc.: extract into constants only when it improves refactoring
- JavaScript semicolons: enabled
- Early Return: preferred
- Ternary: single-line, no nesting
- Type Inference: use when unambiguous
- Comments: explain why, not what
- Abstraction: introduce when actually needed
- Dependency Injection: preferred
- Circular Dependencies: avoid
- Async: `async`/`await` preferred
- Refactoring: proactive
